# STADA Neo Tokyo Grand Prix — версия для показа

Нужен Node.js 22.13 или новее.

## Запуск

Откройте терминал в папке проекта и выполните:

    npm.cmd ci
    npm.cmd run build
    npm.cmd run start -- --hostname 127.0.0.1

Затем откройте http://localhost:3000.

В Windows можно запустить START.cmd — он установит зависимости, соберёт проект и запустит сервер. Первому запуску нужен интернет для зависимостей и шрифтов.

## Страницы

- / — главная и intro
- /leaderboard — живой рейтинг
- /teams — составы команд
- /agenda — программа
- /briefing — новый инструктаж и PDF
- /tv — Live tv
- /admin — Race Control

Форма Race Control использует существующий пароль организатора. Подсказки с паролями и демо-входы удалены из интерфейса. Серверная защита сохранена.

Intro играет один раз за сессию браузера. Для повторного показа откройте сайт в новом приватном окне.

В архиве есть исходники, изображения, исходный MP4, новый PDF, данные и lock-файл. node_modules и .next исключены; они создаются при запуске.

Production-сборка и функциональные проверки проходят. В lint остаются три исходные ошибки правила react-hooks/set-state-in-effect; новых ошибок нет.
